# Example data to test dashboard

This directory contains example datasets derived from an inter-laboratory study (CAMPI: https://www.nature.com/articles/s41467-021-27542-8) to test the dashboard.
Import components for both spectral and community analysis are provided, often in several formats. 

> [!NOTE]
> Data is purely intended for testing out the dashboard functionality. It should not be used to compare peptide identification performance across DB search or *de novo* engines.
